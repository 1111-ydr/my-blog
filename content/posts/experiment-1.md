##Objective
To master the basic file management commands in the Linux terminal.

##Practice Process
In this experiment, I used the VirtualBox Ubuntu environment.
- Created a new directory using `mkdir linux_lab`.
- Listed files using `ls -l`.
- Changed permissions for a script using `chmod +x script.sh`.


This is a solid foundation for further system administration.
