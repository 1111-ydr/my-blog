## Objective
To install a web server on Linux and access it from the host machine.


## Practice Process
I installed Apache2 using `sudo apt install apache2`. Then I checked the service status using `systemctl status apache2`.
I used `curl localhost` in the terminal and accessed the Apache dafault page via the virtual machine's IP address on my host browser.

This experiment gave me a claer understanding of how websites are hosted and served.
